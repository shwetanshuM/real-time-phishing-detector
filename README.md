real-time phishing detector

a machine learning powered chrome extension that detects potentially malicious and phishing urls in real time using custom url feature extraction and a random forest classifier.

this project combines machine learning, cybersecurity, browser extension development, and backend api integration into a complete end to end system.

project overview

phishing websites are designed to trick users into revealing sensitive information such as passwords, banking credentials, and personal data. the goal of this project was to build a lightweight real time phishing detection system that can analyze a website url directly from the browser and classify it as legitimate or phishing.

instead of limiting the project to a notebook based machine learning model, this system was extended into a working chrome extension connected to a flask backend for live predictions.

features
-real time phishing url detection
-chrome extension integration
-flask backend api for inference
-random forest based classification
-custom live url feature extraction
-lightweight and fast predictions
-browser based user interface
-scalable project architecture
